# O céu guardou a gente ✦

Presente interativo mobile-first de Ander para Lil: três meses de namoro, em 08 de novembro de 2026.

## Experiência
- Introdução cinematográfica com céu, lua, cidade e protagonistas ilustrados em SVG.
- Acender três luzinhas do primeiro encontro (20/06/2026).
- Aproximar Ander e Lil com gesto de deslizar, no início do namoro (08/08/2026).
- Descobrir três pedacinhos do relacionamento no dia do aniversário (08/11/2026).
- Carta final e compartilhamento nativo pelo celular.

HTML, CSS e JavaScript puros. Funciona sem backend e não requer login. Os efeitos sonoros opcionais são sintetizados no navegador.

Abra `index.html` ou execute um servidor HTTP estático. Sem dependências de compilação.
